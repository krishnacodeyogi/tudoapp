# 🚀 TaskMaster - Elite Mission Management

TaskMaster is a modern, high-performance Todo application designed for individuals who require a streamlined, visually stunning interface for managing daily tasks and tactical missions.

## ✨ Features

- **Operational Dashboard:** Real-time task tracking with advanced data visualization.
- **Drag-and-Drop Reordering:** Intuitive mission prioritization using `@hello-pangea/dnd`.
- **Intelligent Categories:** Organize tasks into Work, Personal, Health, and Projects.
- **Productivity Intelligence:** completion trend charts powered by `recharts`.
- **Glassmorphic UI:** A premium "Operational Intelligence" aesthetic with full Dark/Light mode support.
- **Data Portability:** Securely export and import mission data as JSON backups.
- **Deadline Alerts:** Proactive toast notifications for missions due within 48 hours.
- **Mobile Responsive:** Fully optimized for seamless operation across all devices.

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite 6, Tailwind CSS v4 (with `@tailwindcss/vite`)
- **Animation:** Framer Motion 12
- **Icons:** Lucide-React
- **State Management:** React Context (Auth & Theme) + Custom Hooks
- **Styling:** CSS Variables + Tailwind Utility Classes

## 🚀 Getting Started

### Prerequisites

- Node.js (Latest LTS version recommended)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 📋 Operational Protocols

- **Authentication:** Local-only simulation for demonstration purposes. Use any email/password.
- **Persistence:** All data is stored in the browser's `LocalStorage`.
- **Security:** Use the "Export Protocol" in the Profile section to create data backups.
